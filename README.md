## 🩸 About The Project

The **Blood Bank Website** is a simple and responsive website designed to provide information about blood donation and make it easier for people to find blood-related services.

The website focuses on a clean design, easy navigation, and an attractive user interface.

> ❤️ **"Your blood can give someone another chance at life."**

---

## ✨ Features

* 🏠 **Home Page** – Introduction to the blood bank
* 🩸 **Blood Groups** – Information about different blood groups
* 👨‍⚕️ **Blood Donor Section** – Donor-related information
* 🔎 **Find Blood** – Search for required blood groups
* 📝 **Donor Registration** – Registration form for blood donors
* 📞 **Contact Section** – Contact information
* 📱 **Responsive Design** – Works on different screen sizes
* 🎨 **Modern UI** – Clean and attractive interface
* ✨ **CSS Animations** – Smooth hover and entrance animations
